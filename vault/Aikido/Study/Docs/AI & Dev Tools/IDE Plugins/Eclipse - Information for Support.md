# Eclipse - Information for Support

When contacting Aikido Support about the Eclipse IDE plugin, please include the information below. This helps us diagnose issues faster and avoid unnecessary back and forth.

### Issue reproducibility

* Is the issue consistently reproducible?
* Does it occur with a single file or with multiple files?
  * If possible share the file with us
* [Did you check connection to Aikido platform?](https://help.aikido.dev/ai-and-dev-tools/ide-plugins-overview/troubleshooting/troubleshooting-ide-plugin-connectivity)

### Plugin & Repository information

* Plugin version
* Operating System
* Link to repository in Aikido
* Usage of Docker, WSL or any other remote development environment

### Support bundle

1. Go to **Help -> Aikido -> Start Support Logging**
2. Reproduce the issue
3. Go to **Help -> Aikido -> Stop Support Logging**
4. Go to **Help -> Aikido -> Export Support Bundle**
5. Share the generated `aikido-support-logs.zip` with Aikido support
