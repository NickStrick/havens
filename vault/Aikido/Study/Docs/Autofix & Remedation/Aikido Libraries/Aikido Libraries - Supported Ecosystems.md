# Aikido Libraries - Supported Ecosystems

Aikido Libraries creates patches for open source packages across the following ecosystems:

* Python
* Java
* JavaScript
* .NET
* Go
* PHP
* Ruby
* Rust

When you enroll a repository, Aikido automatically detects all open source libraries referenced in your lockfiles and manifests - those are the libraries we monitor and fix for you.
