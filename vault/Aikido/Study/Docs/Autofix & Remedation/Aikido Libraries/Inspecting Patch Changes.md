# Inspecting Patch Changes

You can inspect the exact code changes Aikido made to any patched library.

Go to **AutoFix** → **Aikido Libraries** → **Catalog**, find the library, and click **Inspect Aikido Fix**. The diff shows the specific lines changed to address the vulnerability.
