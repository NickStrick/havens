# Cloud Scanning Overview

- **Connect Your Cloud**: Connect your cloud to scan for misconfigurations and security risks
- **Cloud Discovery**: Learn how to search your cloud resources to find resources, risks and misconfigurations across different accounts
- **Cloud Inventory**: Browse a visual map of every asset across your connected cloud environments
- **Custom CSPM Rules**: Set up custom alerts to flag risky cloud configurations
- **Kubernetes Cluster Scanning**: Connect your Kubernetes clusters to scan for misconfigurations and vulnerable images
